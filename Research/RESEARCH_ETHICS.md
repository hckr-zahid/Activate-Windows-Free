# Research Ethics and Publication Notes

- This repository documents defensive static analysis and software-integrity risks.
- Conclusions should remain proportionate to the evidence.
- Do not describe the analyzed project as malware unless separate, sufficient evidence supports that conclusion.
- Do not claim that a behavior is absent merely because a text search did not find it.
- Avoid publishing secrets, personal data, access tokens, or unrelated private information.
- Do not include extracted binaries or republish upstream source files unless their license and redistribution terms permit it.
- Link to the upstream project and identify the exact version/commit instead of implying ownership.
- If you add dynamic-analysis results, record the disposable lab configuration, snapshot state, tools, timestamps, and network controls.
- This research does not recommend executing the script on a production system.
